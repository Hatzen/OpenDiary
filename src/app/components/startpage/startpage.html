Client-Side Zero-Knowledge Encryption

OpenDiary

A private, authenticated cryptographic journal. Multi-layer encryption in your browser with zero server telemetry.

Multi-Layer Cryptography

Authenticated AES-256-GCM, PBKDF2 key derivation (up to 300,000 rounds), unique salt, application pepper, and a deterministic static swap algorithm.

Optional Passphrase Hint

Optionally attach a password reminder stored in the readable file header. Your journal contents and history remain strictly encrypted.

Encrypted Local Snapshots

Revisions are automatically encrypted into browser localStorage in the background. Safe from browser crashes, 100% offline.

DIN A4 Word-Like Editor

Standard DIN A4 page geometry (210×297mm) with rich WYSIWYG formatting, typography controls, tables, print layout, and an integrated Git-like commit timeline.
